### Currently learning...

- 🚀 **[Jev System-1 Model](https://typesafe.ai/)**: Jev is a new type of AI model built for fast/inexpensive decisions. One or two orders-of-magnitude faster/cheaper than an LLM while still having a deep world model based on internet-scale training. There's some significant constraints and tradeoffs. Exploring those now
- ⚙️ **[Convex](https://convex.dev)**: My (previous) new favorite thing. A backend as a service (DB, Workers, Auth, File Storage, Scheduling) based on Typescript. Just write code and the schema/code/etc. just transparently shows up in the cloud. Perfect for AI side-projects as it all just works instantly. Everything is Typescript-defined, so you get excellent code-time error checking which is nice for agentic dev.
- **Rust/tokio**: I decided on Go rather than Rust 5 years ago when looking at modern System languages. I have no idea why, but it was a mistake. Rust is amazing and I love the power of Traits as a first-class language feature (rather than #ifdefs/macros/etc.). Learning programming languages isn't the value it used to be, but I want to get deep enough to guide my agents. And the interesting things I want to do in Rust (including making commits to Convex) use the tokio async threading library. These are both so huge I won't ever get super deep with them...
